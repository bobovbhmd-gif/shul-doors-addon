How rules work together

The schedule is every rule for weekdays, holidays, dates and the rabbi. Two of these may never run on the same door at the same time. When you save one that overlaps another, the system asks which one the door should follow. The one you pick overrides the other, only on the doors they share and only on the days it runs. Each rule shows it: "Overrides …" on the one that wins and "Overridden by …" on the other.

Events (wedding, kiddush, sheva brachos) take over from the schedule during their hours, then the schedule continues. Situations that are switched on take over the same way; one marked "beats everything" also beats events. Open or lock now by hand beats everything. Outside every rule, a door is on its default.

Teach the assistant

Short notes in your own words about how this shul does things. The assistant reads them at the start of every chat and follows them. It never changes by itself: only approved notes count, and a super admin can edit or delete any of them.

New note

Good notes are short and specific: what someone means by a word, which doors go with what, or what to always ask. Notes can't change the safety rules: the assistant still only handles doors, and nothing is saved without your OK.

Holiday names

Rename any holiday or special day to the name your shul uses. The new name shows everywhere: rules, the schedule, the week sheet and the assistant. The schedule itself doesn't change. Tap Hide on any you never use and it drops out of the list when you pick days for a rule. A day that a rule uses can't be hidden.

Situations

Switches like the rabbi switch. Rules marked "Only when this is on" take over while it's on. A situation that beats everything wins even over holidays, for something like Building closed.

Rabbi away dates

Any day in these ranges counts as away. The switch on Home marks every day from today as away until you switch it back.

The default is what a door does when no rule is running. In the live system this list comes from Protector.Net.

Door groups

Use a group in a rule instead of picking doors one by one. Add a door to a group and every rule using the group picks it up. A door can be in several groups.

Import doors

Copy up to four columns from Excel or Google Sheets and paste them here: door ID, name, groups (separate with commas) and default mode. A CSV file works too. Existing doors are updated, new ones added, nothing is deleted.

Badge groups

The groups of cards in Protector.Net. A badge access rule decides when each group's cards work on which doors.

Users and permissions

A super admin sees and changes everything. For anyone else, set each door to Edit, View only or Hidden, and choose whether they can make permanent schedules or only temporary ones. New doors start hidden for them.
