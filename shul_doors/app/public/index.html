Teach the assistant

Short notes in your own words about how this shul does things. The assistant reads them at the start of every chat and follows them. It never changes by itself: only approved notes count, and a super admin can edit or delete any of them.

New note

Good notes are short and specific: what someone means by a word, which doors go with what, or what to always ask. Notes can't change the safety rules: the assistant still only handles doors, and nothing is saved without your OK.

Holiday names

Rename any holiday or special day to the name your shul uses. The new name shows everywhere: rules, the schedule, the week sheet and the assistant. The schedule itself doesn't change. Tap Hide on any you never use and it drops out of the list when you pick days for a rule. A day that a rule uses can't be hidden.

Doors

The default is what a door does when no rule is running. In the live system this list comes from Protector.Net.

Door groups

Use a group in a rule instead of picking doors one by one. Add a door to a group and every rule using the group picks it up. A door can be in several groups.

Import doors

Copy up to four columns from Excel or Google Sheets and paste them here: door ID, name, groups (separate with commas) and default mode. A CSV file works too. Existing doors are updated, new ones added, nothing is deleted.

Badge groups

The groups of cards in Protector.Net. A badge access rule decides when each group's cards work on which doors.
