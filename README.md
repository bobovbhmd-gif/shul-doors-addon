# Shul Doors

Home Assistant add-on that runs Hartmann Protector.Net door schedules by zmanim, Jewish holidays, events and situations.

Install: in Home Assistant go to Settings, Apps, Install app, three dots, Repositories, and add `https://github.com/bobovbhmd-gif/shul-doors-addon`.

This repository holds only the program. Rules, door names, logins and codes are kept on the box, never here.
